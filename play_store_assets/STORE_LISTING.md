## 6. Data Safety Questionnaire Answers

1. **Does your app collect or share any user data?**
   - If using only AdMob: AdMob collects Device/Advertising IDs for ads.
   - For user downloads: All downloads are stored **locally on the user's device** and not transmitted to any developer server.
2. **Is data encrypted in transit?** Yes (HTTPS).
3. **Can users request data deletion?** Users can delete their download history and files at any time directly in the app.
